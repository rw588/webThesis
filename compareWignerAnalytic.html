Microfluidic Talbot Carpet — Wigner formula vs analytic GSM formula

Wigner formula (microFluidicWigner.html)

\[ I_\text{mf}(x,z) = I_0\,\frac{\pi}{\sqrt{A(z)\Delta_v}} \sum_{m,n} a_m a_n\; \underbrace{e^{-\frac{\pi^2(m-n)^2(\lambda z)^2}{A(z)d^2}}}_{\text{order-pair suppression}} \;\underbrace{e^{\frac{2\pi i}{d}(m-n)\,\bar{x}_{mn}\,\Gamma(z)}}_{\text{fringe phase}} \;\sum_{s=-\infty}^{\infty} \underbrace{e^{-\frac{(\bar{x}_{mn}-sd)^2}{2\sigma_I(0)^2}\frac{\pi^2}{A(z)\Delta_v}}}_{\text{displaced source Gaussian}} \underbrace{e^{\frac{-2\pi i}{d}(m-n)sd\,\Gamma(z)}}_{\text{source fringe offset}} \] \[ \bar{x}_{mn} = x - \tfrac{(m+n)\lambda z}{2d},\qquad A(z) = \tfrac{\lambda^2(L+z)^2}{2\sigma_I(0)^2} + \tfrac{\pi^2}{\Delta_v},\qquad \Gamma(z) = 1 - \tfrac{\lambda^2 z(L+z)}{2A(z)\sigma_I(0)^2},\qquad \Delta_v = \tfrac{1}{8\sigma_I(0)^2} + \tfrac{1}{2\sigma_c(0)^2} \]

Analytic GSM formula (microfluidicAnalyticWeb.html)

\[ \begin{aligned} I_{\text{microfluidic}}(x,L+z) &= I_0\frac{\sigma_I(0)}{\sigma_I(L+z)}\sum_{m,n} a_m a_n^* \underbrace{e^{i\frac{2\pi}{d}(m-n)x}}_{\text{spatial fringes}} \underbrace{e^{-i\pi\frac{\lambda z}{d^2}(m^2-n^2)}}_{\text{Talbot phase}} \\[8pt] &\quad\times \underbrace{\exp\!\left[-\frac{\left(x-\frac{m\lambda z}{d}\right)^2+\left(x-\frac{n\lambda z}{d}\right)^2}{4\sigma_I^2(L+z)}\right]}_{\text{displaced intensity envelopes}} \\[8pt] &\quad\times \underbrace{\exp\!\left[-\frac{(m-n)^2\lambda^2z^2}{2\sigma_c^2(L+z)d^2}\right]}_{\text{transverse coherence}} \\[8pt] &\quad\times \underbrace{\exp\!\left[\frac{ik}{2R(L+z)}\left(\left(x-\frac{m\lambda z}{d}\right)^2-\left(x-\frac{n\lambda z}{d}\right)^2\right)\right]}_{\text{wavefront-curvature phase}} \\&\quad\times \sum_{s=-\infty}^{\infty} \underbrace{\exp\left[-\frac{s^2d^2}{2\sigma_I^2(L+z)}+\frac{sdx}{\sigma_I^2(L+z)}-\frac{s(m+n)\lambda z}{2\sigma_I^2(L+z)}+i\frac{2\pi s (m-n)z}{R(L+z)}\right]}_{\text{all source-position dependence}} \end{aligned} \]

Both are evaluated on the same grid with the same parameters and the same normalisation (each source beam has on-axis intensity σI(0)/σI(L+z)). Lengths in d, distances in zT = 2d²/λ.
